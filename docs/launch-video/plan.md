# gokul-hub launch video: plan (/brag-slim, tone: cinematic)

**What:** a Claude Code mod that gives the terminal a VS Code-style sidebar: every tool call as a card, approvals on cards with buttons, a Blast Radius check before risky commands, and plan limits at a glance, in dark or light.
**For:** people who run Claude Code for real work and want to see and steer what it does.
**Sets it apart:** it lives inside Claude Code's own terminal UI. No browser, no separate app.
**Hook:** "Claude is editing your files." / "Can you see every move?"
**Share caption:** see share-copy.txt.

**Format:** landscape 1920x1080, 30fps, 21s. Music 120 BPM (beat 0.5s, bar 2s), A minor; every cut on a beat.
**Identity:** VS Code Dark (#1E1E1E, accent #3794FF, teal #4EC9B0, green #89D185, red #F14C4C, amber #CCA700); SF Pro Display for type, Menlo for code; letterbox bars.
**Real UI:** the recorded screenshots in docs/screenshots (real Claude Code sessions with the mod), framed and pushed into. Nothing invented.
